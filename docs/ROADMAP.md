# BitRunner 开发路线图

原则：**每个阶段结束时游戏都能完整跑起来**，不做"半成品系统堆叠"。

内容审查与规划详见 `docs/CONTENT_DESIGN.md`（物品、敌人、协同、Buff、关卡、设施、标签化与物品等级）。

---

## Phase 0 — 工程基座（1-2 天）

- [ ] 创建 Unity 工程（版本待定，建议 Unity 6 LTS）
- [ ] 目录结构与 asmdef（Core 不引用 UnityEngine）
- [ ] 像素渲染设置：PPU 32、Pixel Perfect Camera、关闭抗锯齿
- [ ] 测试工程可运行（EditMode，NUnit）
- [ ] 基础 ScriptableObject 定义：Item / Bag / Enemy

**验收**：一个空场景 + 一个能跑通的 EditMode 测试。

- [x] 敌方背包渲染（复用 `BagView`）+ 意图预览
- [x] 点击使用装备；拖拽整理背包；目标选择
- [x] 邻接协同（双方同一套规则）

**状态**：已通过。实战模拟第 4 回合胜利，取走 8 件战利品、共 410 价值，剩余 3 格。

## Phase 4 — 搜打撤闭环

- [x] 行动场景生成（地点主题、4–5 个初始行动、3 阶段）
- [x] 行动结果表：物资 / 战斗 / 受伤 / 线索 / 警戒 / 撤退
- [x] 行动物品格、已选行动格、确认、详情、日志（2×2 特殊物品，复用背包系统）
- [x] 已选行动格可接收背包物品；行动/背包页签；单个合法物品校验，多个或无效物品阻止确认
- [x] 武器/护甲耐久：使用/受击各 -1，归零损坏移除；耐久随背包跨战斗保留
- [x] 道具使用动画：道具脉冲 + 火花飞向目标 + 目标面板闪烁；敌人一回合多个道具按「上→下、左→右」依次播放；战斗界面提供动画速度切换（1×/2×/4×，PlayerPrefs 持久化）
- [x] 右键旋转：原地放不下时自动移到同包最近空位（战利品包也可旋转）；战斗内锁定背包布局，战后搜刮阶段恢复；探索界面保留单一背包入口（背包页签 + B 键）
- [x] 容器快捷收纳：把物品拖到容器图标上直接放入（校验容器类型与空间），无需先打开容器窗口
- [x] 潜网阶段数按密钥配置：旷野 4 / 基础 5 / 军用 5 / 信号 5 / 深空 6 / 核心 6（原统一 3）
- [x] 探索辅助标志：光源/消音/护符 I–III（1×1，占背包、耗耐久）；放入已选行动最多 3 个（同系列 1 个）；光源提高警戒，警戒提高遭遇敌人概率；已选格扩为 4×3，辅助以徽章显示
- [x] 探索结果预估：列出所有可能结果、基础→最终概率、辅助/警戒带来的百分点变化；无探索效果或战斗外用途的物品在背包/已选格中灰色显示
- [x] 战斗撤离：玩家随时可撤离，固定消耗一轮（敌人行动一次）后自动脱离（保留背包/生命，无战利品）；敌人失去全部武器后在其回合撤离（无战利品、不计击杀）
- [x] 战斗背包中不可用/冷却中的物品与资源/材料/战利品覆盖灰色遮罩
- [x] 搜刮支持双击/Shift+左键快速转移，以及“搜刮全部”按钮
- [x] 护盾改为消耗能量主动使用；移除每回合免费被动护盾
- [x] 敌人使用与玩家相同的能量/物品系统，从自身背包选择行动
- [x] 敌人装备按种子随机化，保留角色必选槽位；总尺寸不超过 4×3 背包
- [x] 新增同槽位装备变体（废铁甲/重型装甲/短刺/铁棍/钉枪/急救包/小饰物/数据核心）
- [x] 战斗胜利返回当前地点；物资进入格子容器
- [x] 行动权重受生命、背包空间、警戒影响
- [x] 撤退选项与撤离结算
- [x] 阵亡结算（背包全失、保险箱保留）

**验收**：从进图到撤离/阵亡完整跑通，结算数据正确。

## Phase 5 — 基地、债务与商人

- [x] 仓库扩容为 10×6 → 10×8 → 10×10，6 行视口 + 竖向滚动条，支持滚轮/拖动滚动
- [x] 抛射武器消耗背包弹药（脉冲发射器）
- [ ] 情报台、终端
- [x] 保险箱：2×2 → 3×2 → 3×3（保险中枢），仅 1×1 非武器护甲、死亡保留、战斗中不可使用
- [x] 搜刮阶段可把战利品拖入保险箱
- [x] 保险箱扩容（并入 C-7 子空间保险网络中枢）
- [x] 中央处理器 Lv.1–5（2×2 → 5×4）+ 15 张芯片（生命/底甲/能量）
- [ ] JSON 存档 + 版本号 + 自动保存（出征前/回基地）

**验收**：连续 7 次出征后自动缴债；bit 不足进入失败；债务无上限（爬到 2000/周后恒定）→ 结局只能靠击杀 Boss 或逃亡；商人每日刷新 6 件货架且可拖拽买卖；潜网舱组合副本可进入，矿场/制作站每日可用。
**状态**：基地 → 出征 → 战斗 → 战利品 → 回基地结算闭环已跑通（Day 1 → Day 2，背包持久）；设施页签（8 个：商人/潜网/矿场/制作/芯片/保险/仓储/通讯）、拖拽购买/出售/购回、组合副本、旷野低危层、矿场收取、制作、堆叠、护盾/弹药、行动/背包页签、跨战斗耐久、随机敌人配装与敌人物品化 AI 已验证。**357 个 EditMode 测试通过**。存档系统尚未实现。

## 风险清单

| 风险 | 应对 |
|---|---|
| 格子 bug 拖垮后期 | Phase 1 纯 C# + 测试，不碰 UI |
| 战斗节奏拖沓 | 敌人意图 + 单场 3-6 回合硬约束 |
| 硬核惩罚劝退 | 阵亡只丢本次新捡的战利品，自带装备一定回来 |
| 美术量爆炸 | 先做 20 件物品的完整视觉，再批量 |
| 系统膨胀 | 每个新想法先问：是否复用现有系统 |
| 敌人配装内容量爆炸 | MVP 手工 3 套模板；之后做"预算生成器"，按战斗/战利品比例自动摆包 |
| 敌方背包信息过载 | 4×3 小格 + 悬停详情；最多 2 个敌人同屏 |
| 对称系统导致 AI 太强/太蠢 | 确定性贪心 + 固定优先级；先做可读性，再谈聪明 |
| 击杀后战力滚雪球 | 背包空间是天然上限；敌人装备不超模，收益与风险同源 |
